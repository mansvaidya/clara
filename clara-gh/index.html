Plausibility rules
  1. R1. Executive function can't be two levels better than working memory, because the same task measures both.
  2. R2. Delayed (episodic) recall can't be better than immediate recall.
  3. R3. Attention is Lowest only when at least two core dimensions are also Lowest.
  4. R4. One Lowest with every other dimension Typical is excluded, except Lowest episodic recall (the amnestic pattern).
